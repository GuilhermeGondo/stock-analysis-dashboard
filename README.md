# Equity Research Dashboard

Interactive stock analysis dashboard built with Python, Streamlit, and Yahoo Finance API.

## Features

- Real-time stock market data collection
- Valuation metrics (P/E, P/B, Dividend Yield)
- Upside analysis based on custom target prices
- Historical price analysis
- Moving averages and volatility calculations
- Interactive financial dashboard with Plotly

## Technologies

- Python
- Streamlit
- Plotly
- Pandas
- yFinance
